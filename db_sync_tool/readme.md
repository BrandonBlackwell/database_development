# 🧩 Database Sync Tool

A lightweight internal CLI tool for syncing table data between production and development MariaDB databases.

---

## 🚀 Overview

This tool provides a command-line interface (CLI) to synchronize tables from a source database (e.g., production) to a target database (e.g., development or test).  
It’s built using **Python 3**, **SQLAlchemy**, and standard libraries only — no external frameworks required.

You can use it for:
- Refreshing dev/test environments with production data
- Partial or full table syncs
- Automated or manual sync jobs
